# Student Performance Analyzer

## Project Description

A basic Python project that analyzes student performance.

## Features

- Calculate total marks
- Calculate percentage
- Assign grades
- Identify pass/fail students
- Find class topper
- Calculate class average

## Technologies Used

- Python
- Lists
- Dictionaries
- Loops
- Conditional Statements
- Functions

## How to Run

Run the `test.py` file using Python.

## Example

The program takes student marks as input and generates:

- Total marks
- Percentage
- Grade
- Pass/Fail status
- Topper
- Class average
